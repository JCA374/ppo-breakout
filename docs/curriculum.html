Curriculum

There is no curriculum here: from the first step the agent plays the real game, with the same rules it is tested on. Only two things make training easier than the test, and both are standard for Atari:

What training sees that the test does not

  • A lost life ends the training episode ("episodic life"). The value estimate learns that losing the ball is the end of the world, which is a clearer signal than "one of five lives is gone". The game itself continues; only the bookkeeping changes. The test plays all 5 lives as one game.
  • Rewards are clipped to +1. A red brick (7 points) and a blue one (1 point) both count as +1 while learning, so one learning rate fits all games. The test counts the real score.

What changes over the run

  • The learning rate falls linearly from 2.5·10⁻⁴ to 0 over the 10 M frames ("annealing"), so late updates are small.
  • The policy's own randomness (entropy) falls as it becomes sure of itself. An entropy bonus (0.01) keeps it from collapsing too early.

Milestones: expected before the run, measured during it
